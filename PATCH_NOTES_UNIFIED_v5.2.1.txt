MOSTIK v5.2.1 — ЕДИНЫЙ КУМУЛЯТИВНЫЙ ПАТЧ

Этот архив объединяет изменения всех ранее подготовленных патчей MOSTIK:
- v5.1.6 reminders + skills
- v5.1.7 full fixes
- v5.1.8 unified fixes
- v5.1.9 unified fixes
- v5.2.0 unified fixes
- v5.2.1 unified fixes

ВАЖНО:
Архив является полной текущей версией проекта, а не набором отдельных diff-файлов.
То есть его содержимое уже включает накопленные изменения предыдущих патчей.

Основные изменения:
1. Исправлена проверка паролей и защита от ошибок malformed hash/timingSafeEqual.
2. Повторяемые напоминания: weekly/monthly, календарные вхождения, завершение с переносом на следующее вхождение, ограничение monthly на последний день месяца.
3. Навигация сохраняет текущую вкладку после действий.
4. Навыки доступны внутри Training, отдельный пункт из «Ещё» убран.
5. В календаре добавлены «+ Запланировать» и «🔔 Напоминание».
6. Для владельца домашнее задание выделено в отдельный режим с полноценным завершением сессии и метриками.
7. Для владельца/кипера ветеринарный раздел показывает «Ветеринарные назначения» и чек-лист выдачи препаратов.
8. Для животных добавлено копирование ID и прикрепление существующего животного по ID.
9. MOSTIK Insight вынесен в верхнюю область администратора.
10. «Установить MOSTIK» перенесено в Settings.
11. Добавлены шаблоны тренировок для trainer/admin: создание, удаление, выбор навыков, длительность и предзаполнение тренировки.
12. Добавлена единая верхняя панель функций для выбранной вкладки: Animals, Observations, Training, Food, Calendar, Vet, Enrichment, Journal, Admin и др.
13. Реализованы быстрые действия обогащения среды и редактирования плана питания.
14. Реализована функция repeatRecord() для повторения записей.
15. Исправлены связанные миграции и устранено дублирование номера миграции: animal_access/navigation теперь 022.

Проверки:
- JavaScript/MJS: node --check для всех файлов
- package.json: JSON parse
- ZIP integrity: unzip -t
