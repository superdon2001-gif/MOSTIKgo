# MOSTIK — исправление создания животного у кипера

## Причина
В `public/app.js` после открытия формы выполнялась строка обращения к несуществующему элементу `#cancelAddAnimal`:

```js
document.querySelector('#cancelAddAnimal').onclick=close;
```

В разметке формы такого элемента нет — используется `#cancelCreateAnimal`. Из-за этого JavaScript получал `null.onclick`, обработчик `submit` формы не успевал установиться, и браузер выполнял обычную отправку `<form>`, из-за чего страница просто перезагружалась без создания животного.

## Исправление
Удалено прямое обращение к отсутствующему элементу и оставлено безопасное подключение существующей кнопки:

```js
document.querySelector('#closeAddAnimal')?.addEventListener('click',close);
```

Кнопка `#cancelCreateAnimal` уже обрабатывается отдельным обработчиком выше.

## Проверка
`node --check public/app.js` проходит без синтаксических ошибок.

Модель владения не изменялась: кипер по-прежнему может создавать животное как его владелец (`owner_id = текущий кипер`) и получать его в своё окружение.
