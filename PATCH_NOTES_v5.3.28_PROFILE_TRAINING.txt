MOSTIK v5.3.28 — исправление профиля животного и фиксации тренировок

1. Профиль животного
- Добавлена кнопка «Профиль» прямо на карточку животного для всех ролей с доступом.
- Кнопка открывает существующие данные профиля в режиме просмотра.
- Поля миграции 044 теперь сохраняются через PUT /animals/:id: среда, социальная структура, пищевой профиль, любит, избегает, опыт общения с людьми.
- Редактирование профиля осталось отдельной функцией для владельца/администратора.

2. Тренировки
- Исправлена передача и сохранение полей миграции 043 и 047 в основном API: цель, план, итог, мостик, подкрепления, ошибка и реакция.
- История тренировок получает эти поля из базы.
- Исправлен расчёт «сегодня» в интерфейсе тренировки: используется локальная дата пользователя, а не UTC.

3. Шаги навыков
- GET /animals/:id/skills теперь возвращает step_type и criterion_met.
- Создание шагов в основном API также сохраняет step_type и criterion_met.

4. Миграции
- Новых миграций нет. Используются существующие 043–047.
