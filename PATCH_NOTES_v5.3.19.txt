# MOSTIK v5.3.19 — единый патч

## 1. Киппер — удаление животного из окружения
- В карточке животного для роли keeper добавлена кнопка «Удалить из моего окружения».
- Удаляется только запись keeper в animal_access.
- Животное, его история и доступ владельца не удаляются.
- Полное удаление по-прежнему доступно только владельцу своего животного и администратору.

## 2. Автозаполнение
- SMART-подсказки теперь обновляются при фокусе, вводе и изменении поля.
- Учитывается текущий вид животного.
- Для вида и подвида подключается каталог животных.
- Дубли подсказок удаляются.
- «Другое…» сохраняет пользовательское значение в SMART.

## 3. Пошаговое обучение
- Обучение расширено до полноценного маршрута по приложению.
- Пользователь должен выполнить действие в подсвеченной области, прежде чем перейти дальше.
- Обучение показывает текущий шаг и прогресс.
- Маршрут проходит через животное, наблюдения, рацион, SMART-шаблоны, тренировку, календарь, ветеринарию, аналитику и настройки.
- Обучение можно повторить из Настроек.

## ВАЖНО
- Миграция 004_demo_seed НЕ изменялась. На production необходимо сохранить её точную production-версию.
- Новая миграция для этих функций не требуется: изменения используют существующую animal_access и существующие SMART-таблицы.
