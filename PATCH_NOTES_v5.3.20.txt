MOSTIK v5.3.20 — animal save + searchable animal catalog

1. Исправлен UX сохранения нового животного: кнопка показывает «Сохраняю…», ошибка возвращает кнопку, отсутствие ID считается ошибкой, после POST выполняется проверка, что созданное животное действительно появилось в списке.
2. «Вид» и «Подвид» получили настоящий выпадающий каталог с фильтрацией по мере ввода.
3. В списке есть «Другое…» для собственного значения; пользовательский текст сохраняется как введённое значение.
4. Каталог вида содержит все 30 вариантов из animal_catalog; при временной недоступности API есть безопасный фронтенд-fallback тех же вариантов.

6. Общий SMART-автокомплит больше не дублирует специальные поля вида/подвида.
7. То же автозаполнение доступно при редактировании профиля животного.
8. Миграции не изменялись; 004_demo_seed не трогать.
