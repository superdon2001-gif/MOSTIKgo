MOSTIK v5.3.16 — каталог животных и подвиды для кипера

- Добавлена миграция 049_animal_catalog_subspecies.sql.
- Добавлен каталог 20 популярных зоопарковых и 10 домашних животных.
- Добавлен API /api/animal-catalog для автозаполнения вида и подвида.
- Кипер может создавать новое животное из меню «Добавить животное».
- Для кипера поле «Порода» заменено на «Подвид».
- Для кипера подвид подставляется из каталога в зависимости от выбранного вида.
- Для кипера при создании животное добавляется в его окружение через animal_access.
- Для владельца/администратора сохранено поле «Порода».
- Существующие миграции 001–048 не изменяются.
