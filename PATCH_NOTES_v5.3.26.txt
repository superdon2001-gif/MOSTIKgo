MOSTIK v5.3.26 — «Все животные»: ошибки загрузки и счётчик задач
================================================================
Включает v5.3.25 (ложное «Всё под контролем»). Копировать поверх v5.3.25.

1. «Все животные»: ошибки не превращаются в нули
-----------------------------------------------
Раньше, если запрос today не удавался для животного, home() подставлял пустые
массивы, и статистика показывала 0 тренировок/наблюдений/рациона/ветеринарии,
а событий — «Сегодня записей ещё нет».
Теперь такой ответ помечается failed:true, и:
  - если не загрузилось часть животных — над цифрами красная плашка
    «Данные загружены не полностью — не удалось получить: <имена>. Цифры ниже
    неполные.» + кнопка «Повторить»; пустой список событий пишет
    «Записей по загруженным животным нет.»;
  - если не загрузилось ничего — вместо нулей только плашка с «Повторить».

2. Счётчик «N задач» соответствовал списку не всегда
----------------------------------------------------
Бейдж показывал общее число, а карточек выводилось не больше 12.
Теперь: «12 из 20 задач» + кнопка «Показать все (20)»; после нажатия
показываются все, бейдж — «20 задач». Добавлено склонение: 1 задача /
2–4 задачи / 5+ задач.

Файлы: app.js, app.css, sw.js (в корне и в public/), кэш SW -> mostik-v5.3.26-cache.
No DB migrations in this patch.

Проверка: (1) DevTools -> Network -> блокировать /api/today*, открыть
«Все животные» -> плашка вместо нулей; (2) при >12 задачах бейдж «12 из N»
и кнопка «Показать все».
