# MOSTIK 5.0.0

## Unified workspace
- Главная объединяет «Сегодня» и «Обзор»
- Единый контекст животного: одно животное / Все животные
- Унифицированная навигация: Главная, Животные, Журнал, Тренировка, Ветеринария, Аналитика, Календарь, Ещё

## Журнал
- Единая лента событий: тренировки, наблюдения, ветеринария, питание, домашние задания, напоминания, запланированные события
- Фильтры по типу события
- Сортировка по дате и имени животного
- В режиме «Все животные» учитываются только доступные пользователю животные

## UX
- Дополнительные разделы перенесены в «Ещё», чтобы уменьшить визуальный шум
- Навигация и контекст «Все животные» работают через единый shell
- Сохранены существующие database migrations и функции
