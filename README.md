# MOSTIK v4.4.25

Analytics dashboard upgrade based on v4.4.24.

## What changed
- Replaced the training statistics screen with a visual **Analytics** dashboard.
- Analytics adapts to the selected animal or **All animals**.
- Periods: 7, 30, 90 days, 1 year.
- Visuals include trend line, animal comparison bars, behavior bars, activity bars, event donut, attention signals, and an all-animals comparison table.
- Analytics is available to owners, trainers, keepers, veterinarians, and administrators.
- No new database migration is required.
