# MOSTIK v5.1.0 — Roadmap v2 (пункты 1–7)

## 1. Журнал
- Защита от не-массивов во всех местах рендера (Today + Journal).
- Тип событий «Лекарства» (medication) с фильтром и иконкой.

## 2. Ветеринария и лекарства
- Динамическая форма «Состояние / Назначение», периоды, auto-administrations.
- «✓ Препарат выдан», повтор назначений.

## 3. Календарь
- «+ Запланировать» подставляет выбранный день.
- Повторяющиеся напоминания (схема + UI).

## 4. Навыки + тренировки
- Автокопирование полей предыдущего шага при добавлении нового.
- Кнопка «🎯 Навыки» из экрана Тренировка.
- Во время сессии доступны «Шаги навыка» выбранных навыков.

## 5. Питание
- Поле «Продукты» (название | кол-во | ккал).
- Удаление записи питания.
- API: products jsonb + DELETE.

## 6–7. Рационы + Excel / печать
- Миграция 017: diets, diet_periods, diet_meals, diet_meal_products.
- Полный API: список/создание/редактирование/удаление рационов, приёмы пищи, продукты, периоды, копирование дня, активный рацион на дату.
- UI «🍽 Рацион» в меню «Ещё»:
  - создание рациона
  - приёмы пищи с продуктами
  - копирование дня на диапазон (1-6 и т.п.)
  - расчёт калоража базового дня (только если указан)
  - 🖨 Пустая форма рациона (печать)
  - 📥 Импорт CSV/Excel (простой CSV: time,meal,product,quantity,calories)

## UI
- Улучшен контраст блока «Требует внимания».


## UX-правка (вкладки)
- Раздел **Питание** переименован в **Рацион**.
- Модуль планирования переименован в **План питания** и встроен во вкладку «Рацион» (подвкладки: Записи / План питания).
- У продуктов явное поле **граммы** (формат: название | граммы | ккал).
