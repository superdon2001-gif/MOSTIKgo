MOSTIK v5.3.22

1. Пошаговое интерактивное обучение по конкретным действиям, отдельное для каждой активной роли.
2. Обучение объясняет смысл роли и доступные возможности, затем проводит по реальным кнопкам и формам.
3. Для создания животного шаги включают добавление, выбор создания, имя, вид и сохранение.
4. Для кипера: животные → наблюдение → рацион → запись кормления → обогащение среды → календарь → напоминание.
5. Для владельца: животные → наблюдение → рацион → домашнее задание → календарь → ветеринария → аналитика.
6. Для тренера: тренировка → шаблоны → запуск → завершение → домашнее задание → наблюдение → аналитика.
7. Для ветеринара: ветеринария → запись → анализы → результат анализа → история → аналитика.
8. Для администратора: администрирование → пользователь → роли → доступ к животным → служебные функции → ошибки → аналитика.
9. Усилено сохранение животных кипером: self-heal animal_access для старых баз, повторная привязка и проверка фактического доступа.
10. Миграции не изменялись, включая 004_demo_seed.
