MOSTIK v5.3.29 — профиль человека

Добавлено:
- фото аккаунта в правом верхнем углу;
- клик по фото открывает профиль человека;
- профиль показывает ФИО, email, все назначенные роли и активную роль;
- добавлена личная аналитика: занятия, средний успех, наблюдения, рацион, ветеринария, домашние задания, животные в доступе, события и активные дни за 30 дней;
- изменение имени и фото профиля;
- фото хранится в аккаунте (до 2 МБ, PNG/JPG/WEBP/GIF);
- форма фото следует настройке скругления темы: при «Без скругления» квадрат, при остальных вариантах круг.

База:
- новых миграций нет;
- добавляется только идемпотентная колонка users.avatar_data при запуске API.

Проверка:
- node --check api.mjs — OK
- node --check public/app.js — OK
- npm run build — OK
